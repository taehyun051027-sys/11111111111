# 야구 — 투타겸업 개인 모드

제공된 Baseball Superstars 2013 v1.2.9 APK를 대상으로 만든 Android 개인 모드입니다. 원래 게임의 화면과 메뉴, 경기 진행을 유지하고 나만의 선수의 투타겸업과 무한 능력 모델, 팀·선수 식별 정보와 원화를 통합합니다.

## 구성

- Android 앱 이름: **야구**
- 별도 설치 패키지: `com.taehyun.yagu`
- CPU: `arm64-v8a`, `armeabi-v7a`
- 유니버셜 리그 진입, 나만의 선수의 선발투수 및 타자 동시 등록
- 나만의 선수의 홈런·탈삼진 결과 경로와 기존 엔진의 실제 득점·아웃 처리 연결
- `Unbounded` 태그를 사용하는 무한 능력 모델과 기존 엔진용 수치 어댑터
- 기존 UI 안의 무한 표시, 새 상대 팀 이름·로고·유니폼, NPC 이름 `1`–`310`

## 정확한 팀 이름

| 구분 | 이름 |
|---|---|
| 유지 구단 | 대구 푸마즈 |
| 리그 상대 | 알파, 베타, 감마, 델타, 엡실론, 제타, 에타, 세타, 요타 |
| 세계대회 | 입실론, 파이, 카이, 프사이, 오메가 |

## 무한의 의미

16진수는 표기법입니다. `0xffff` 같은 최대 정수는 무한이 아닙니다. 이 패치는 별도의 타입과 태그로 `Unbounded`를 표현합니다. 원본의 유한 정수 필드와 물리·애니메이션·성장 테이블은 안전한 어댑터 값을 받습니다. 화면에 보이는 무한과 어댑터의 유한 값을 같은 값이라고 설명하지 않습니다.

퍼펙트게임의 조건인 상대 피안타·볼넷·실점은0을 유지합니다. 실제 경기의 이닝·아웃·득점 처리와 개인의 무한 능력·기록 상태는 구별합니다. 9이닝 경기를 마치려면 실제 종료 조건이 유한해야 합니다.

## 테스트와 배포

APK 서명·압축 무결성 검사, 양쪽 ABI의 실제 삽입 명령 실행 검사, Android 실행 검증은 서로 다른 검증입니다. 상세 결과와 남은 제한은 함께 제공되는 검증 보고서를 기준으로 확인하세요. 정적 검사만으로 모든 기기에서 전체 게임이 완벽히 작동한다고 주장하지 않습니다.

웹 테스트는 같은 APK가 실행 중인 Android 화면을 전송하고 터치 입력을 전달하는 방식입니다. 별도로 다시 만든 웹 게임이 아닙니다. 개발 실행 세션의 연결 상태, 전송 지연, 무음 여부를 화면에 표시합니다.
