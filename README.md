# 야구 — 투타겸업 개인 모드

사용자가 제공한 Baseball Superstars 2013 v1.2.9 APK의 메뉴·육성·경기·조작을 유지하면서, 대구 푸마즈의 나만의 선수를 투타겸업 선수로 만드는 Android 개인 모드다. 내 선수는 타입으로 표현한 무한 능력과 개인 기록을 갖고, 동료와 상대는 원본 계산식 안의 강한 유한 선수로 구성한다.

**현재는 개발 후보이며 완성 릴리스가 아니다.** 이전 `e4adc580…efc0e28` APK의 실제 경기는 8:0으로 끝났다. 동일 MyPlayer가 9이닝 동안 81구 모두 스트라이크·27연속 탈삼진·무피안타·무실점을 기록했고, 경기 후 저장·재실행하여 다음 경기로 진행한 것도 확인했다. 반면 실제 타격 결과는 **5타수 3홈런 2삼진**으로, 전타석 홈런 조건은 실패했다. 이 결과와 실패를 새 합본의 성공 증거로 옮겨 쓰지 않는다. [기능별 검증과 버전 구분](docs/COVERAGE.md)

## 무한의 의미와 실제 경기

`Scalar.kind == UNBOUNDED`는 모든 유한 정수와 구분된다. 레벨250·능력10000·훈련7·스킬10·강화99는 원본 테이블과 물리 계산에 전달하는 호환 값이며 내 선수의 실제 상한이 아니다. 감사한 개인 목표·이벤트·로컬 순위·자원 소비·멘탈 대결은 타입 상태를 직접 사용한다. `0xffff`나 최대 정수에∞라는 이름만 붙인 구현이 아니다.

한 경기의 점수·아웃·이닝·투구와 경기 후 실제 성적표는 유한한 경기 카운터다. 상대 피안타·볼넷·실점, 패배, ERA·WHIP와 실책 같은 불리한 개인 지표는0으로 둔다. 무한한 저장 공간이나 무한한 경기 길이를 구현하는 목표가 아니다.

SP는 원래 학습·소모·사용SP 원장을 통과하면서 재고를 소진하지 않는다. 장비 강화는 원래0–99행 안에서 계산하고, 이미 무한인 부품의 추가 강화는 기존 MAX 안내를 사용한다. 멘탈과 팀 평균은 기존 능력/레벨에서 파생되며 새 선수 필드를 추가하지 않는다. [SP](build-work/native/SKILL_POINTS_MAP.md) · [멘탈](build-work/native/MENTAL_DUEL_MAP.md) · [팀 평균](build-work/native/TEAM_MEAN_MAP.md)

## G·Star와 개발판 상점 가격

G·Star 지갑은 정확한 소유 옵션과 공통 메뉴 또는 소유 커리어에서만 활성화한다. 원래 로컬 구매 효과를 사용하며 서버 계정 잔액·실제 결제·영수증·성공 응답을 새로 만들지 않는다.

**원래 서버 가격을 그대로 보존했다고 주장하지 않는다.** 원본 상점 가격 중 일부는 서버 응답으로 채워지는 BSS에 있고, 오프라인 APK만으로 그 공식 가격을 복원할 수 없다. 개발판 카탈로그는 APK에 포함된 표를 근거로 유한한 로컬 가격을 명시하고, 내장 가격이 없는 헤어/염색은 **1 G**, 스킨은 **1 Star**로 정하는 정책이다. 이는 개발판의 가격이며 원래 운영 서버의 가격이라는 뜻이 아니다.

지갑 핵심2,212건·표시338건, SP1,604건의 명령 검증과 카탈로그 초기화·상점 진입·Android 실제 구매는 각각 다른 검증이다. 카탈로그 모듈52곳/ABI·6,012건 검증을 마쳐 최종369곳 합본에 포함했다. Android 실제 구매는 미확인이다.

## 검증과 남은 범위

새 합본의 SP1,604건, 멘탈3,032건, 팀 평균692건, 타자 출전 보호994건을 양 ABI에서 검사했다. 원본 포스트시즌·컵 대진 선택240건은 본인 대진이 플레이 경로로, 다른 팀끼리의 대진이 원래 시뮬레이션으로 가는 것을 확인했다. 이는 전체 시즌이나 모든 경기의 Android 실기 완료 횟수가 아니다.

이전 e4 후보의9개 수비 이닝은 같은 APK로 진행했지만, 그 경기 첫 타석은 checkpoint4에서 시작했다. 따라서 경기 전체를 한 APK의 처음부터 끝까지 성공한 시험으로 기록하지 않는다. 0볼넷은 별도 BB 숫자 관찰이 아니라27연속3구 삼진·27아웃에서의 추론이다. 새 합본의 전타석 홈런, 늦은 수동 입력, 다음 경기 선발·타순, 자원 소비·모든∞표시, 후속 상점 구매는 검증을 계속한다.

ARM64 실기, 전체 시즌·세계대회, 모든 언어·장비 조합은 미검증이다. 원본32칸 시즌 순위 배열, 연차127→128 좁힘, 과거 기록10칸 경계도 남아 있어 무제한 시즌을 보장하지 않는다.

## 실제 APK 웹 스트림과 빌드

웹은 실행 중인 **같은 APK의 실제 Android 화면·터치·게임 소리**를 전달한다. 실제 프레임·입력·비영 PCM 수신은 확인했으며, 소유자 비공개 웹 테스트는 [https://yagu-universal-play.taehyun051027.chatgpt.site](https://yagu-universal-play.taehyun051027.chatgpt.site)에 배포했다. 실행기 연결·릴레이 지연을 조정 중이며 브라우저의 전체 플레이 성공을 확인했다는 뜻은 아니다. 에뮬레이터가 꺼지면 웹도 오프라인이다.

빌드는 [BUILD.md](BUILD.md), 정확한 범위는 [CURRENT_SCOPE.md](docs/CURRENT_SCOPE.md), 구조는 [IMPLEMENTATION.md](docs/IMPLEMENTATION.md), 기능별 증거는 [COVERAGE.md](docs/COVERAGE.md)를 따른다. 공개 소스의 포함·제외 기준은 [SOURCE_RELEASE_AUDIT.md](docs/SOURCE_RELEASE_AUDIT.md)의 **감사 시점 스냅샷**과 최종 패키징 매니페스트를 구분해 읽는다.

입력 APK는 다음 SHA256과 정확히 일치해야 한다.

```text
2c7792387492b6c3deebb52c162eeb0e147461de1c49e2d148490bec30194484
```

원본 APK·원본 라이브러리·SDK·컴파일러·개인키·비밀번호·에뮬레이터 저장 데이터는 공개 소스에 포함하지 않는다. 최종 APK 해시는 위 표를 따르며 소스 ZIP 해시는 패키징 보고서에 별도로 기록한다.  과거 checkpoint4의 해시를 최신 결과로 사용하지 않는다.
